# 📚 Deitel - C: How to Program (6. Baskı) - Çözümler ve Uygulamalar

![alt text](image.png)

Bu depo, Harvey Deitel ve Paul Deitel'ın yazarlığını yaptığı **"C: How to Program, Sixth Edition"** (C: Nasıl Programlanır, Altıncı Baskı) kitabındaki seçilmiş alıştırmalar, örnekler ve projeler için kişisel çözümlerimi ve uygulamalarımı içerir.

## 🌟 Proje Hakkında

Bu proje, C programlama dilini daha derinlemesine öğrenme ve kitaptaki kavramları pratik uygulamalarla pekiştirme hedefiyle oluşturulmuştur. Her bölüm, ilgili alıştırmaların çözümlerini ve/veya önemli programlama örneklerini içeren ayrı bir klasörde düzenlenmiştir.

* **Amaç:** Kitabın öğretim materyalini pekiştirmek ve programlama becerilerini geliştirmek.
* **Kitap Versiyonu:** Sixth Edition (Altıncı Baskı).
* **Programlama Dili:** C.C++

## 📂 Depo Yapısı

Depo, kitabın bölüm sırasına göre düzenlenmiştir. Her klasör, o bölümdeki uygulamaları içerir.


## Örnek Klasör İçeriği

Her alıştırma ve uygulama, genellikle kendi **`.c`** dosyası içinde bulunur ve dosya adı, ilgili bölüm ve alıştırma numarasına göre adlandırılmıştır (örneğin, `alistirma_3_15.c`).

---

## 🛠️ Nasıl Çalıştırılır

Bu projeyi yerel makinenizde çalıştırmak için bir C derleyicisine (tercihen **GCC** veya **Clang**) ihtiyacınız olacaktır.

1.  **Depoyu Klonlayın:**
    ```bash
    git clone https://github.com/Semihdogan23/Deitel---C-How-To-Program-Sixth-Edition.git
    ```

2.  **İlgili Klasöre Gidin:**
    ```bash
    cd Deitel---C-How-To-Program-Sixth-Edition/Chapter_XX_Bölüm_Adı
    ```

3.  **Kodu Derleyin (GCC Örneği):**
    ```bash
    gcc alistirma_adi.cpp -o alistirma_adi
    ```

4.  **Programı Çalıştırın:**
    ```bash
    ./alistirma_adi
    ```
